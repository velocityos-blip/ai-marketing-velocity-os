# Technical SEO diagnostics

## Method

Review crawl records for response chains, directives, canonical conflicts, mobile rendering and page performance. Trace each suspected issue to a concrete URL and signal.

## Deliverable

A technical backlog with reproduction evidence, scope, urgency and validation steps.

## Review

Avoid claims about crawl behavior or performance without dated observations.
