# Agent-readable site review

## Method

Use supplied public-page markup to trace how a reader identifies the entity, offering, price and intended action. Compare visible labels, semantic landmarks and machine-readable descriptions.

## Deliverable

A field-level readability report and examples of clearer labels or metadata.

## Review

Separate observations about supplied markup from assumptions about a rendered page.
