# Marketing budgeting

## Method

Start with the business goal, available budget and planning period. Separate committed costs from flexible spend, allocate by validated opportunity and learning value, and model downside, expected and upside cases using stated assumptions.

## Deliverable

A budget table with initiative, amount or range, timing, owner, expected signal, assumptions, contingency and reallocation trigger.

## Review

Do not present modeled returns as forecasts. Label all assumptions, include full costs and set spending caps.
