# Backlink profile analysis

## Method

Normalize a supplied link export by referring domain and target page. Compare anchor patterns, topical context and lost links across equal time windows.

## Deliverable

A link profile with source coverage, concentration risks and recoverable links.

## Review

A suspicious pattern alone cannot establish spam or justify removal.
