# Firecrawl extraction review

## Method

Use supplied crawl results to compare discovered URLs with expected sections. Inspect representative extracted text and identify omissions, duplicates or navigation noise.

## Deliverable

A crawl coverage summary and a list of pages requiring render or extraction checks.

## Review

An absent extracted element does not prove it is absent from the rendered page.
