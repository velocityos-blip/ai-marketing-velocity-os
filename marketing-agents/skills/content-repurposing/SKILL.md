# Content repurposing

## Method

Start with one source asset and its intended audience. Extract only supported ideas, then adapt each derivative to the channel's native format, length, context and CTA. Maintain source links and factual consistency.

## Deliverable

A repurposing map connecting the source asset to channel-specific drafts, required edits, owner and distribution sequence.

## Review

Do not present a derivative as independent research. Preserve attribution and verify quotes, dates, numbers and context against the source.
