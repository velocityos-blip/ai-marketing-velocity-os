# Growth loops

## Method

Trace how a user action creates value for the next prospective customer. Identify where the cycle loses participants.

## Deliverable

Diagram the loop in steps and define conversion and cycle-time metrics.

## Review

Check for genuine customer value on both sides of the loop.
